# WEEKLY BATCH

Plan and build a whole week in one go. Best done on a weekend.

```text
WEEKLY BATCH. Page: <page-slug>. Week starting: <YYYY-MM-DD>. Videos: <4-5, or use page.md>.

1. Read ai-handoff-summary.md, CLAUDE.md, pages/<page>/page.md and the latest file in analytics/.
2. topic-picker (week mode): give me 3 week plans as multiple choice, recommended first.
   Each plan: the topics, series balance, posting days and times (US Eastern and Dubai time).
3. After I pick:
   a. Create one EP folder per video. For each: fact-checker, script-writer, shot-planner.
   b. Split the credit plan across my Flow accounts in credits.csv. Show the total per account.
   c. Give me ONE generation sheet: every Flow prompt for the week, grouped by episode, with the
      exact file names. I generate everything in one sitting.
   d. Give me all narration texts in one block for Higgsfield, with the file name for each.
4. When I say "assets done": assemble each video one by one (video-assembler, QA, thumbnail-maker).
5. publisher: captions and YouTube blocks for all videos, then fill schedule.csv and give me a
   step-by-step posting checklist for Meta Business Suite (Facebook + Instagram), Threads and
   YouTube Studio (or Postiz if it is set up).
6. Update handoff.md and ai-handoff-summary.md after each finished video, so a new chat can continue.
   If this chat gets long, finish the current video, update the handoffs, and tell me to open a new
   chat with prompts/continue.md.
```
