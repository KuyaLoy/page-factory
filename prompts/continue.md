# CONTINUE

Use when a chat got long, an earlier chat stopped halfway (setup, a video, a batch), or you come back later.

```text
CONTINUE. Read ai-handoff-summary.md, CLAUDE.md and studio.md. Tell me in 3 lines where we are and
what the next action is, then do it. If the HQ setup isn't finished, continue the hq-setup checklist
from the first unticked item. If an episode in episodes.csv is still "in progress", ask me whether to
finish it or drop it. Open handoff.md only for the section you need.
```
