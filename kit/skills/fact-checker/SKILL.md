# Fact checker

## Steps
1. List every claim the story needs (who, what, when, where, numbers, "first", "only").
2. For each claim find 2 independent reliable sources: encyclopedias, museum or university pages,
   national archives, reputable news, published books. Wikipedia is a starting point; cite what it
   cites when you can.
3. Mark each claim:
   - Confirmed: 2 sources agree.
   - Disputed: sources disagree or historians debate it. The script must say so ("historians argue",
     "legend says").
   - Myth: drop it.
4. Write the Sources table in brief.md with URLs and the date accessed.

## Rules
- Never invent numbers, dates, names or quotes. If a number can't be confirmed, round it and say
  "about", or drop it.
- Fewer than 2 good sources for the core claim: tell Loy and suggest another topic.
- No medical, legal or financial advice in scripts.
- Keep the sources: they protect the page if a viewer challenges a video.
