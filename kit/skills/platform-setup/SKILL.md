# Platform setup

## How to guide
- One platform at a time. Numbered steps. Wait for "done" before the next platform.
- The user logs in and clicks. Never ask for or type passwords or codes.
- Apps change their menus. If a step doesn't match what the user sees, search the platform's own help
  center for the current steps and give the updated path.
- Save every link, handle and status in pages/<slug>/page.md (Platforms table) right away.

## Already have the account?
Ask for the link. Then check with the user: profile photo, name, bio, category, professional or creator
mode, 2-step verification, link to the other accounts. List what's missing and fix it together.

## YouTube (do this first, it needs a Google account)
1. Turn on 2-Step Verification for the Google account.
2. youtube.com > profile picture > Create a channel. Pick the page name and @handle.
3. Verify the phone number at youtube.com/verify (unlocks custom thumbnails and longer uploads).
4. YouTube Studio > Customization: banner, picture, description with keywords, links to the other pages.
5. YouTube Studio > Settings > Upload defaults: category, language, audience "No, it's not made for
   kids" only when the content is for a general audience.
6. Monetization: YouTube Studio > Earn shows progress to the Partner Program. Check that the user's
   country is on the YPP country list (support.google.com/youtube/answer/7101720).

## Facebook Page
1. Facebook > Menu > Pages > Create new Page: name, category, bio.
2. Profile picture and cover from the brand pack. Set the @username.
3. Open the Professional Dashboard. Monetization tab: see what the Page can join, express interest in
   Content Monetization (invite-only), note Stars (500 followers for 30 days).
4. Turn on 2-factor authentication for the Facebook account.

## Instagram
1. Create the account (or use an existing one). Switch to a professional account: Creator.
2. Profile picture, name, bio, link.
3. Link it to the Facebook Page in Accounts Center so one Reel can go to both.

## Threads
1. Install Threads and log in with the Instagram account. Import the profile. Keep it public.

## TikTok
1. Sign up in the app. Pick the @username, photo and bio.
2. Keep a personal or creator account unless the user needs a business account. Check TikTok's help
   center for the current difference in monetization and music access before switching.
3. Monetization: TikTok Studio > Monetization shows what the account can join. Programs and countries
   change; check the official page and note the rules (for example, minimum video length) in page.md.

## Posting tools (free first)
| Platform | Free way to post and schedule |
|---|---|
| Facebook + Instagram | Meta Business Suite (business.facebook.com): Create reel, pick both, schedule |
| Threads | Threads app |
| YouTube | YouTube Studio: Upload, set visibility to Schedule |
| TikTok | TikTok Studio (web) or the app |
Later, one dashboard for all: Postiz (AGPL-3.0, self-hosted, needs the user's own developer apps).

## Output
page.md Platforms table filled: platform, link, handle, mode, 2FA on, monetization status, posting tool.
